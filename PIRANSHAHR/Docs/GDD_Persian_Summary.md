## فصل ۱ — کانسپت

**پیرانشهر** شبیه‌ساز رانندگی جهان‌باز فوتورئالیستیک، آفلاین، فارسی، برای اندروید.
بازیکن در بازسازی دقیق خیابان‌ها، بازار و محله‌های پیرانشهر رانندگی، مأموریت انجام و آزاد می‌گردد.

## فصل ۲ — گیم‌پلی

- **Free Roam:** گشت آزاد، فیزیک واقعی، عابر و ترافیک.
- **مأموریت‌ها:** تاکسی داخل‌شهری، تحویل کالا، تعمیرگاه.
- **پیاده‌روی:** ورود/خروج خودرو، باز کردن درب‌ها، ورود به ۵ ساختمان شاخص.
- **آب‌وهوا:** باران/برف/مه مستقل از فصل؛ زمان قابل انتخاب (نه زنده).
- **ذخیره:** خودکار + ۳ پروفایل مستقل.

## فصل ۳ — خودروها

| خودرو | کلاس | توضیح |
|---|---|---|
| پیکان | Hero | پرتیراژترین، فیزیک دقیق |
| سمند | ملی | لوکس‌تر |
| پراید | سبک | شهری |
| تویوتا کرولا / رنو لوگان | بین‌المللی | مرجع |

هر خودرو صدای موتور، بوق، تایر مجزا (MetaSounds).

## فصل ۴ — شهر

- مختصات واقعی WGS84 → UTM 38N → UE Local
- World Partition 256m + HLOD
- ۲۰۰+ ساختمان در مرکز، گسترش تدریجی به کل شهر
- جاده‌ها: Spline با پیاده‌رو، جدول، تابلو فارسی

## فصل ۵ — UI فارسی

- فونت وزیرمتن، RTL کامل، اعداد فارسی، نیم‌فاصله
- HUD: سرعت، دور موتور، سوخت، نقشه، سوخت‌یاب
- تنظیمات گرافیک: Performance / Balanced / Ultra (هدف ۳۰ FPS روی POCO X3 Pro)

## فصل ۶ — صدا

- موتور هر خودرو جدا، محیط بازار، اذان، بوق، باران
- دیالوگ فارسی با زیرنویس

## فصل ۷ — بهینه‌سازی

- Forward Rendering + MSAA 4x (نه Deferred)
- Vulkan + ASTC 6×6
- LOD دستی (Nanite خاموش در موبایل)
- Pool Size 600MB, Draw Call <120

## فصل ۸ — نقشه راه

- M1 (2026-12-31): مرکز ۲km² + یک خودرو + HUD
- M2: ترافیک + هوش مصنوعی + آب‌وهوا
- M3: مأموریت‌ها + صدا + Photo Mode
- M4: گسترش کامل شهر + پولیش نهایی
