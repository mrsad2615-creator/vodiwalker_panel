# BLACK HOLE · TON 618

تجربه‌ای سه‌بعدی، تعاملی و فارسی با الهام از کوازار ابرپرجرم TON 618؛ یک تصویرسازی علمی‌ـ‌سینمایی است، نه شبیه‌سازی عددی. در پاسخ به درخواست اجرای هم‌زمان چند موتور/لایه‌ی توانمند، هسته‌ی صحنه‌ی Three.js، shaderهای اختصاصی GLSL روی WebGL 2، ذرات GPU و حرکت‌های سبک CSS با هم کار می‌کنند. لایه‌های گرافیکی سه‌بعدی از یک WebGL context مشترک استفاده می‌کنند تا کیفیت و روانی حفظ شود، بی‌آن‌که چند context مستقل بی‌دلیل باتری و حافظه‌ی گوشی را مصرف کنند.

## دانلود و نصب اندروید

[دانلود مستقیم APK نسخه‌ی 1.1.0](https://github.com/mrsad2615-creator/vodiwalker_panel/releases/download/black-hole-v1.1.0/black-hole.apk). فایل را روی گوشی باز کنید؛ اگر اندروید اجازه خواست، نصب برنامه از همان مرورگر یا فایل‌منیجر را فعال کنید. این APK با کلید debug امضا شده و برای نصب مستقیم و آزمایش است، نه انتشار در Google Play.

نسخه‌ی اندروید همه‌ی فایل‌های صفحه و قلم فارسی را درون خودش دارد؛ برای اجرا وب‌سرور یا اینترنت لازم نیست. کیفیت WebGL 2 به سخت‌افزار و Android System WebView دستگاه بستگی دارد؛ اگر WebGL در دسترس نباشد، نمای جایگزین فعال می‌شود.

## آنچه در نسخه‌ی 1.1 تازه شده

- قاب آغازین لوگوموشن سیاه‌چاله، سبک و کوتاه؛ با رعایت کاهش حرکت
- صحنه‌ی الهام‌گرفته از TON 618، دیسک برافزایشی و جت‌های آبی نسبیتی
- حلقه‌ی فوتونی روشن‌تر و لکه‌های نورانی که پیوسته پیرامون سیاه‌چاله می‌گردند
- اصلاح و تقویت خمیدگی دیداری نور و امکان تنظیم درخشش حلقه
- قاب دوربین بازتر در شروع، تنظیم فاصله‌ی دقیق، چهار زاویه و بازنشانی سریع
- ستاره‌های رنگی‌تر و درخشان‌تر، با کیفیت تطبیقی برای دستگاه‌های کم‌توان
- کلید روشن/خاموش برای جت‌ها و حلقه‌ی نور؛ کنترل سرعت، ذرات، کیفیت و نمایش کشندی
- آیکون برنامه و نشان رابط بازطراحی‌شده

## کنترل‌ها

- صحنه را با ماوس یا لمس بکشید تا زاویه‌ی دید تغییر کند؛ برای زوم از چرخ ماوس، ژست دو انگشت یا دکمه‌های پایین صفحه استفاده کنید.
- در «تنظیمات تصویر» فاصله‌ی دوربین، درخشش حلقه، سرعت گردش و شدت ذرات را تنظیم کنید؛ جت‌ها و حلقه‌ی نور هم کلید جداگانه دارند.
- «مقایسه» و نوار آن، نمایش دیداری خمیدگی نور را کم‌وزیاد می‌کند؛ این جلوه برای توضیح ساده‌ی مسیر نور است، نه حل عددی نسبیت.
- «دانش فضا» پنج مفهوم را با توضیح کوتاه و تصویرهای آموزشی نشان می‌دهد؛ از درس گسیختگی کشندی می‌توان نمایش سرنوشت ستاره را آغاز کرد.
- نمایش کشندی مکث و اجرای دوباره دارد. حالت سینمایی و تمام‌صفحه نیز از نوار بالای صفحه در دسترس‌اند.
- کیفیت رندر به‌طور خودکار با توان دستگاه سازگار می‌شود و از تنظیمات می‌توان آن را تغییر داد.

## ساخت APK از سورس

نیازمندی‌ها: Node.js 22، JDK 17، Android SDK با Platform 35 و Build Tools 35.0.0، و Gradle 8.11.1.

از پوشه‌ی `black_hole/` اجرا کنید:

```bash
npm ci
npm run check
npm test
npm run build:standalone
gradle --no-daemon -p android assembleDebug
```

APK در `android/app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود. گردش‌کار GitHub Actions همین بررسی‌ها و build اندروید را اجرا می‌کند، فایل را در GitHub Release منتشر می‌کند و نسخه‌ی CI را برای مدت محدود به‌صورت artifact هم نگه می‌دارد.

## نسخه‌ی وب و توسعه

- `npm run build` نسخه‌ی یکپارچه با FastAPI را در `dist/` می‌سازد؛ مسیر اجرا `/black-hole/` است.
- `npm run build:standalone` نسخه‌ی مستقل و آماده‌ی میزبانی را در `standalone/` می‌سازد.
- اجرای مستقل: `python3 -m http.server 8080 --directory standalone`
- توسعه: `npm run dev -- --host 0.0.0.0 --base /`
- آزمون‌ها: `npm run check` و `npm test`

برای توسعه‌ی وب Node.js نسخه‌ی 20.19+ یا 22.12+ لازم است.
