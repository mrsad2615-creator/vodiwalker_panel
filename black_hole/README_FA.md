# BLACK HOLE — فراتر از افق رویداد

تجربه‌ای سه‌بعدی، تعاملی و کاملاً فارسی از سیاه‌چاله؛ ساخته‌شده با Three.js و shaderهای سبک WebGL. این تصویرسازی علمی‌ـ‌سینمایی است، نه شبیه‌ساز عددی.

## نصب روی اندروید

فایل `black-hole.apk` نسخه‌ی نصب مستقیم اندروید است. آن را روی گوشی دانلود و باز کنید؛ اگر اندروید اجازه خواست، نصب برنامه از همین مرورگر یا فایل‌منیجر را فعال کنید. APK ارائه‌شده با کلید debug امضا شده و برای نصب مستقیم/آزمایش است؛ برای انتشار در Google Play باید با کلید انتشار شخصی امضا شود.

برنامه‌ی اندروید، فایل‌های وب و قلم فارسی را داخل خودش دارد و برای اجرا یا نمایش سه‌بعدی به وب‌سرور، حساب کاربری یا اتصال اینترنت نیاز ندارد. پشتیبانی از WebGL 2 به سخت‌افزار و WebView/Android System WebView دستگاه بستگی دارد؛ در نبود آن، نمای جایگزین برنامه نمایش داده می‌شود.

## ساخت APK از سورس

نیازمندی‌ها: Node.js 22، JDK 17، Android SDK با Platform 35 و Build Tools 35.0.0، و Gradle 8.11.1.

از پوشه‌ی `black_hole/` اجرا کنید:

```bash
npm ci
npm run build:standalone
gradle --no-daemon -p android assembleDebug
```

APK در مسیر `android/app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود. گردش‌کار GitHub Actions همین بررسی‌ها و build را انجام می‌دهد و APK را به‌صورت artifact قابل‌دانلود ارائه می‌کند.

## نسخه‌ی وب و توسعه

- `npm run build` نسخه‌ی یکپارچه با FastAPI را در `dist/` می‌سازد؛ مسیر اجرا `/black-hole/` است.
- `npm run build:standalone` نسخه‌ی مستقل و آماده‌ی میزبانی را در `standalone/` می‌سازد.
- برای اجرای نسخه‌ی مستقل: `python3 -m http.server 8080 --directory standalone`
- برای توسعه: `npm run dev -- --host 0.0.0.0 --base /`
- آزمون‌ها: `npm run check` و `npm test`

نیازمندی توسعه‌ی وب: Node.js نسخه‌ی 20.19+ یا 22.12+.

## کنترل‌ها

- کشیدن صحنه: چرخش دوربین؛ چرخ ماوس یا دکمه‌های پایین: زوم و بازنشانی
- «خمیدگی نور» و «مقایسه»: روشن/خاموش‌کردن اثر و مقایسه‌ی مسیر نور
- «سرنوشت یک ستاره»: اجرای نمایش کشندی؛ امکان مکث و اجرای دوباره
- «دانش فضا»: پنج درس کوتاه درباره‌ی افق رویداد، دیسک برافزایشی، خمیدگی نور، گسیختگی کشندی و جت‌های نسبیتی
- تنظیمات: سرعت گردش، شدت ذرات و کیفیت تطبیقی تصویر

اگر WebGL 2 در دسترس نباشد، برنامه با تصویر جایگزین و پیام روشن ادامه پیدا می‌کند.
