## پیش‌نمایش ۰٫۳ · Studio

- **میز کار:** پرسش، خلاصه، ترجمه و پیش‌نویس. انتخاب یک تا سه موتور، تأیید نام/مدل/نشانی هر مقصد، پاسخ جریانی جداگانه، اندازه‌گیری زمان تا اولین متن و پایان پاسخ، کپی یا انتقال به ویرایشگر یادداشت. هیچ ارسال و مقایسهٔ پنهانی وجود ندارد.
- **Gemini:** نشانی رسمی آماده و فهرست مدل زنده با کلید شخصی. گزینهٔ جدا برای URL سفارشی با هشدار مقصد و عدم انتقال کلید از مقصد قبلی. زمان فهرست و خطاهای HTTP نشان داده می‌شوند؛ فهرست، تست تولید متن یا تضمین سهمیه نیست.
- **مدل اپل از مک:** اتصال اختیاری بدون دسترسی مستقیم به Siri یا سرویس ابری اپل. کد پل زیر `companion/apple-mac/` روی مک سازگار با HTTPS خصوصی، توکن شخصی و SDK رسمی اجرا می‌شود؛ بخشی از APK نیست. آزمون واقعی استنتاج اپل به آن سخت‌افزار نیاز دارد.
- **حریم خصوصی:** آفلاین پیش‌فرض روشن است و WAN و LAN را مسدود می‌کند. خواندن فهرست کلید و درخواست فهرست را ارسال می‌کند، نه پرامپت. تولید فقط پس از تأیید مقصدها صورت می‌گیرد. پرامپت، دستور متنی نوع کار و تنظیمات مدل ارسال می‌شوند، نه یادداشت، حافظه، سابقه یا عکس. هر موتور ممکن است جداگانه سهمیه یا هزینه مصرف کند.
- **یادداشت‌ها** بدون شبکه کار می‌کنند. پاسخ‌های میز کار در حافظهٔ نشست هستند، مگر به انتخاب شما در یادداشت ذخیره شوند. لغو محلی اتصال تضمین نمی‌کند سرور پردازش یا محاسبهٔ درخواست دریافت‌شده را متوقف کند.

### نگهداری داده

کلید API با AES-256-GCM و کلید غیرقابل‌استخراج Android Keystore رمز می‌شود؛ nonce تازه و AAD شامل شناسهٔ پروفایل، فرمت، نوع شبکه و Base URL است. ciphertext و تنظیمات پروفایل در یک تراکنش Room تغییر می‌کنند. فیلد ورود کلید پوشیده و دیالوگ آن `FLAG_SECURE` دارد. بدنهٔ یادداشت‌ها و جدول‌های تاریخچه/حافظه در فضای خصوصی اپ هستند، **نه** در یک DB رمزنگاری‌شده. backup/انتقال دادهٔ اپ غیرفعال است. حذف پروفایل کلید را در سمت سرویس لغو نمی‌کند. هیچ مجوز ضبط صدا، ثبت صفحه، Accessibility یا نمایش شناور در این نسخه وجود ندارد.

## ساخت و راستی‌آزمایی

پیش‌نیاز: **JDK کامل ۲۱**، Android SDK Platform 36 و Build Tools 36.0.0، و دسترسی به مخازن رسمی Gradle، Google Maven و Maven Central. حداقل دستگاه Android 8 / API 26 است. پوشهٔ `dana-android` را در Android Studio باز کنید و Gradle JDK را روی ۲۱ بگذارید. برای ابزار خط فرمان `JAVA_HOME` و `ANDROID_HOME` را به مسیرهای محلی خود تنظیم کنید. `local.properties` و فایل امضای انتشار نباید commit شوند.

```bash
cd dana-android
sdkmanager --licenses
sdkmanager 'platforms;android-36' 'build-tools;36.0.0' 'platform-tools'
./gradlew --no-daemon :core:domain:test :core:data:testDebugUnitTest :core:data:lintDebug :app:lintDebug :app:assembleDebug
./gradlew :app:installDebug                     # با گوشی یا امولاتور متصل
./gradlew :core:data:connectedDebugAndroidTest # Room، DataStore و Android Keystore
```

در Windows از `gradlew.bat` استفاده کنید. `assembleDebug`، فایل `app/build/outputs/apk/debug/app-debug.apk` با شناسهٔ `ai.dana.preview` می‌سازد. این **APK پیش‌نمایش با امضای دیباگ** است، نه APK تولیدی یا نسخهٔ فروشگاه. برای به‌روزرسانی روی نصب قبلی، Android امضای یکسان می‌خواهد؛ ساخت‌های CI ممکن است کلید دیباگ متفاوت داشته باشند. پاک کردن نسخهٔ قبلی داده‌های محلی آن را پاک می‌کند. نسخهٔ production (`ai.dana`) به کلید انتشار پایدار نیاز دارد و `:app:assembleRelease` بدون کلید خصوصی خروجی امضاشدهٔ انتشار نمی‌دهد.

گردش‌کار `Dana Android` در هر تغییر مرتبط تست‌ها، lint، بیلد، صحت امضای فایل و قرارداد شبکهٔ پل خصوصی مک (روی Linux، بدون مدل اپل) را بررسی می‌کند. پس از نصب و اجرای APK روی شبیه‌سازِ API 34 و آزمون Room، DataStore و Keystore، فایل خام را به‌عنوان artifact قرار می‌دهد. روی شاخهٔ این تحویل، push با نشان `[dana-apk]` پس از عبور از همین بررسی‌ها یک GitHub prerelease با دانلود مستقیم و فایل SHA-256 می‌سازد. بدون این نشان، artifact در خلاصهٔ اجرا قرار می‌گیرد و ممکن است برای دانلود به ورود به GitHub نیاز داشته باشد. تست‌های شبکه از اتصال‌های واقعی HTTPS به MockWebServer محلی و پاسخ‌های SSE کنترل‌شده استفاده می‌کنند؛ کلید و سهمیهٔ یک سرویس عمومی را نیاز ندارند و جایگزین آزمون دسترسی از داخل ایران نیستند.

Room به نسخهٔ schema پایبند است و destructive migration ندارد. طرح نسخهٔ ۱ از خروجی واقعی Room در اجرای موفق ثبت شده است. CI طرح خروجی را با فایل ثبت‌شده مقایسه می‌کند؛ تغییرات عمدی باید با نسخه و migration مناسب بازبینی شوند.

**خارج از این پیش‌نمایش:** گفت‌وگوی چندمرحله‌ای و تاریخچهٔ مقایسه، OCR/ثبت صفحه، گفتار، اجرای اکشن و حافظهٔ هوشمند. هیچ‌کدام را به‌عنوان قابلیت آمادهٔ نصب فرض نکنید.
