# DANA AI · دانا

دانا یک پروژهٔ **Android بومی با Kotlin و Compose** است. این پوشه از پنل Python همین مخزن مستقل است. [گزارش فارسی فاز صفر](docs/00-audit-fa.md) تصمیم‌های معماری و برنامهٔ توسعه را ثبت کرده است؛ آن گزارش وضعیت آغاز پروژه است، نه فهرست امکانات نسخهٔ فعلی.

## دریافت APK آزمایش‌شده

[دانلود مستقیم DANA AI 0.2 Preview](https://github.com/mrsad2615-creator/vodiwalker_panel/releases/download/dana-preview-44186660013-1/DANA-AI-preview.apk) · [فایل SHA-256](https://github.com/mrsad2615-creator/vodiwalker_panel/releases/download/dana-preview-44186660013-1/SHA256SUMS.txt) · [نتیجهٔ بیلد و آزمون](https://github.com/mrsad2615-creator/vodiwalker_panel/actions/runs/44186660013)

APK با commit `1f26e9d` ساخته شد. بیلد debug و release، lint، ۲۶ آزمون JVM (از جمله آزمون HTTP/TLS هم‌زمان)، ۶ آزمون ذخیره‌سازی روی Android API 34، نصب و بازشدن صفحهٔ مقایسه در حالت آفلاین و تأیید امضای APK در CI موفق بودند. هش APK منتشرشده با هش artifact خامِ همان اجرا یکسان است. این فایل امضای دیباگ دارد.

## پیش‌نمایش ۰٫۲

- **مقایسهٔ موتور:** یک پرسش را به ۱ تا ۳ پروفایل انتخاب‌شده بفرستید. OpenAI-compatible و Gemini native هر کدام SSE خود را در درخواست HTTPS جداگانه اجرا می‌کنند. پاسخ‌ها به‌صورت جریانی، جدا و با نام موتور نمایش داده می‌شوند. خطای یک موتور پاسخ دیگری را متوقف نمی‌کند.
- **حریم خصوصی:** حالت کاملاً آفلاین پیش‌فرض روشن است و WAN و LAN را می‌بندد. برای هر ارسال، دانا نام و Base URL تمام مقصدها را قبل از تأیید نشان می‌دهد. فقط متن همین پرسش همراه دستور فارسی دانا و تنظیمات مدل فرستاده می‌شود؛ یادداشت، سابقه، تصویر و حافظه ارسال نمی‌شوند. هر موتور می‌تواند جداگانه هزینه یا سهمیه مصرف کند.
- **خانه و یادداشت‌ها:** رابط فارسی RTL با Vazirmatn و وضعیت شبکهٔ واقعی Android. ساخت، ویرایش و حذف یادداشت به اینترنت نیاز ندارد و در Room روی دستگاه ماندگار است. نتایج مقایسه در این پیش‌نمایش فقط در حافظهٔ جلسه‌اند و به تاریخچهٔ دائمی نوشته نمی‌شوند.
- **تاب‌آوری:** کلید به مقصد و پروتکل پروفایل مقید است. redirect و retry خودکار غیرفعال‌اند، سقف متن و مهلت درخواست مشخص است و خطا به فارسی برای همان موتور نمایش داده می‌شود. رفتن به تب دیگر، خروج برنامه از پیش‌زمینه یا زدن «توقف دریافت پاسخ» اتصال محلی را لغو می‌کند؛ لغو تضمین نمی‌کند که سرور درخواست دریافت‌شده را پردازش یا محاسبه نکند.

### راه‌اندازی موتور

۱. در «تنظیمات ← افزودن پروفایل» قالب API مستند سرویس را انتخاب کنید. Base URL شامل **پیشوند API** است، نه مسیر نهایی فراخوانی. معمولاً OpenAI-compatible از `https://HOST/v1` و Gemini native از `https://HOST/v1beta` استفاده می‌کند. `HOST` را با میزبان واقعی جایگزین کنید.

۲. شناسهٔ مدل و، در صورت نیاز سرویس، کلید حساب خودتان را فقط در فیلد «کلید API» بگذارید. Gemini native کلید می‌خواهد. OpenAI-compatible باید SSE و پارامتر `max_tokens` را بپذیرد. اپ هیچ کلید یا مسیر ارائه‌دهندهٔ اجباری ندارد. برای میزبان LAN نیز HTTPS با گواهی مورد اعتماد Android لازم است.

۳. حالت کاملاً آفلاین را خاموش کنید، در تب «مقایسه» موتورهای دلخواه را انتخاب کنید، پرسش را بنویسید و پس از بررسی مقصدها ارسال کنید. دانا وضعیت شبکه را از Android می‌خواند اما از روی آن دسترسی سرویس یا فیلترینگ را حدس نمی‌زند. دسترسی از ایران و شرایط هزینه به ارائه‌دهنده و حساب شما وابسته است.

### نگهداری داده

کلید API با AES-256-GCM و کلید غیرقابل‌استخراج Android Keystore رمز می‌شود؛ nonce تازه و AAD شامل شناسهٔ پروفایل، فرمت، نوع شبکه و Base URL است. ciphertext و تنظیمات پروفایل در یک تراکنش Room تغییر می‌کنند. فیلد ورود کلید پوشیده و دیالوگ آن `FLAG_SECURE` دارد. بدنهٔ یادداشت‌ها و جدول‌های تاریخچه/حافظه در فضای خصوصی اپ هستند، **نه** در یک DB رمزنگاری‌شده. backup/انتقال دادهٔ اپ غیرفعال است. حذف پروفایل کلید را در سمت سرویس لغو نمی‌کند. هیچ مجوز ضبط صدا، ثبت صفحه، Accessibility یا نمایش شناور در این نسخه وجود ندارد.

## ساخت و راستی‌آزمایی

پیش‌نیاز: **JDK کامل ۲۱**، Android SDK Platform 36 و Build Tools 36.0.0، و دسترسی به مخازن رسمی Gradle، Google Maven و Maven Central. حداقل دستگاه Android 8 / API 26 است. پوشهٔ `dana-android` را در Android Studio باز کنید و Gradle JDK را روی ۲۱ بگذارید. برای ابزار خط فرمان `JAVA_HOME` و `ANDROID_HOME` را به مسیرهای محلی خود تنظیم کنید. `local.properties` و فایل امضای انتشار نباید commit شوند.

```bash
cd dana-android
sdkmanager --licenses
sdkmanager 'platforms;android-36' 'build-tools;36.0.0' 'platform-tools'
./gradlew --no-daemon :core:domain:test :core:data:testDebugUnitTest :core:data:lintDebug :app:lintDebug :app:assembleDebug
./gradlew :app:installDebug                     # با گوشی یا امولاتور متصل
./gradlew :core:data:connectedDebugAndroidTest # Room، DataStore و Android Keystore
```

در Windows از `gradlew.bat` استفاده کنید. `assembleDebug`، فایل `app/build/outputs/apk/debug/app-debug.apk` با شناسهٔ `ai.dana.preview` می‌سازد. این **APK پیش‌نمایش با امضای دیباگ** است، نه APK تولیدی یا نسخهٔ فروشگاه. برای به‌روزرسانی روی نصب قبلی، Android امضای یکسان می‌خواهد؛ ساخت‌های CI ممکن است کلید دیباگ متفاوت داشته باشند. پاک کردن نسخهٔ قبلی داده‌های محلی آن را پاک می‌کند. نسخهٔ production (`ai.dana`) به کلید انتشار پایدار نیاز دارد و `:app:assembleRelease` بدون کلید خصوصی خروجی امضاشدهٔ انتشار نمی‌دهد.

گردش‌کار `Dana Android` در هر تغییر مرتبط تست‌ها، lint، بیلد و صحت امضای فایل را بررسی می‌کند. پس از نصب و اجرای APK روی شبیه‌سازِ API 34 و آزمون Room، DataStore و Keystore، فایل خام را به‌عنوان artifact قرار می‌دهد. روی شاخهٔ این تحویل، push با نشان `[dana-apk]` پس از عبور از همین بررسی‌ها یک GitHub prerelease با دانلود مستقیم و فایل SHA-256 می‌سازد. بدون این نشان، artifact در خلاصهٔ اجرا قرار می‌گیرد و ممکن است برای دانلود به ورود به GitHub نیاز داشته باشد. تست‌های شبکه از اتصال‌های واقعی HTTPS به MockWebServer محلی و پاسخ‌های SSE کنترل‌شده استفاده می‌کنند؛ کلید و سهمیهٔ یک سرویس عمومی را نیاز ندارند و جایگزین آزمون دسترسی از داخل ایران نیستند.

Room به نسخهٔ schema پایبند است و destructive migration ندارد. طرح نسخهٔ ۱ از خروجی واقعی Room در اجرای موفق ثبت شده است. CI طرح خروجی را با فایل ثبت‌شده مقایسه می‌کند؛ تغییرات عمدی باید با نسخه و migration مناسب بازبینی شوند.

**خارج از این پیش‌نمایش:** گفت‌وگوی چندمرحله‌ای و تاریخچهٔ مقایسه، OCR/ثبت صفحه، گفتار، اجرای اکشن و حافظهٔ هوشمند. هیچ‌کدام را به‌عنوان قابلیت آمادهٔ نصب فرض نکنید.
