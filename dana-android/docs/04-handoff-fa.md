## شروع در کمتر از یک دقیقه

1. دانا با **آفلاین کامل** باز می‌شود. «گفتگو» را باز کنید و `یادداشت کارهای فردا` را وارد کنید. «بازبینی ← تأیید و اجرا» را بزنید و نتیجه را در «یادداشت‌ها» ببینید. برای تایمر نمونهٔ `تایمر ۵ دقیقه` است. از «گفتگو ← ابزارها» نمونه‌ها و تنظیمات گوشی نیز در دسترس‌اند.
2. برای پاسخ مدل، از «تنظیمات» یکی از موتورهای **Gemini، میزبان خصوصی Ollama/LM Studio، پل مک یا API سازگار با OpenAI** را تنظیم کنید. فهرست مدل‌ها فقط با زدن دکمهٔ دریافت، از نشانی نشان‌داده‌شده خوانده می‌شود. اگر فقط یک مدل در پاسخ باشد در فیلد خالی مدل قرار می‌گیرد؛ برای چند مدل، یکی را انتخاب کنید. آفلاین کامل را فقط وقتی خاموش کنید که اجازهٔ اتصال می‌دهید.
3. در «گفتگو» موتور را روی **خودکار** بگذارید یا نام یک موتور را دستی انتخاب کنید. «بازبینی» قبل از ارسال تمام مقصدها، متن، بخش همراه از گفتگو، موارد حافظه (اگر فعال و مرتبط باشند) و وجود تصویر را نشان می‌دهد. اگر می‌خواهید یک ورودی را واقعاً به چند مدل هم‌زمان بدهید از تب «مقایسه» استفاده کنید، نه مسیر خودکار گفتگو.
4. برای حفظ گفتگو، از «حریم خصوصی» داخل گفتگو ذخیرهٔ دورهای کامل را روشن کنید. بایگانی، جستجو در متن و عنوان، تغییر نام و حذف را در همان تب گفتگو دارد. گفتگوی تازه به‌صورت موقت پیش‌فرض است. ذخیره‌سازی، گذشتهٔ یک گفتگوی موقت را به‌طور خودکار وارد بایگانی نمی‌کند.

## «خودکار» دقیقاً چه می‌کند؟

- پس از تنظیم یک‌باره، تا **سه پروفایل واجدشرایط** را اولویت‌بندی می‌کند: میزبان خصوصی؛ سپس Gemini؛ بعد سایر موتورهای تنظیم‌شده. یک پروفایل Gemini یا پل اپل بدون کلید در فهرست خودکار قرار نمی‌گیرد. مدل مک برای تصویر یا زمینه‌ای که در سقف مسیر مک جا نشود انتخاب نمی‌شود. مدل انتخاب‌شدهٔ سازگار با OpenAI یا Gemini باید طبق پشتیبانی خود سرویس، تصویر را بپذیرد.
- هر بار فقط **موتور اول** را اجرا می‌کند؛ در بعضی خطاها مثل قطع اتصال، timeout، `403`، `429` یا آماده نبودن مدل مک، فقط پیش از دریافت متن و فقط به گزینهٔ بعدی که در همین ارسال تأیید کرده‌اید می‌رود. خطای TLS، رد ایمنی یا پاسخ ناقص بعد از دریافت متن موجب تغییر موتور نمی‌شود. انتخاب دستی، جایگزین ندارد. توقف محلی تضمین نمی‌کند سروری که قبلاً درخواست را گرفته هزینه‌ای منظور نکند.
- هیچ موتور یا شمارهٔ مدلی حدس زده یا به‌طور پنهانی اضافه نمی‌شود. باز کردن برنامه ارسال نمی‌کند. خودکار به معنی ساختن حساب، آوردن کلید محرمانه یا دسترسی رایگان تضمین‌شده نیست. کلید Gemini را از Google AI Studio فقط **داخل برنامه** وارد کنید. اپل به [پل اختیاری روی مک سازگار](03-engine-guide-fa.md) و توکن همان پل نیاز دارد؛ Siri یا API ابری اپل نیست.
- حالت کاملاً آفلاین، **هم WAN و هم LAN** را قطع می‌کند. اگر مدل محلی روی میزبان جدا می‌خواهید، باید شبکه را مجاز کنید. خود APK وزن مدل مولد متن ندارد؛ در حالت قطع شبکه، OCR، یادداشت، حافظه و ابزارهای محلی همچنان کار می‌کنند.

### اتصال محلی بدون کلید ابری

اگر Ollama یا LM Studio را روی کامپیوتر خودتان اجرا می‌کنید، API سازگار با OpenAI را با **HTTPS خصوصی و گواهی معتبر برای اندروید** در اختیار گوشی قرار دهید. در دانا «تنظیمات ← اتصال Ollama یا LM Studio»، آدرس پایه مانند `https://<نام-معتبر-میزبان>:8443/v1` را بدهید. میزبان باید به IP خصوصی‌ای که گوشی می‌بیند resolve شود؛ تنظیم LAN آدرس عمومی یا پراکسی سیستم را قبول نمی‌کند. سرور باید `GET /v1/models` و `POST /v1/chat/completions` با SSE و `max_tokens` را پشتیبانی کند. اگر سرور خصوصی شما برای درخواست‌ها احراز هویت ندارد، فیلد کلید را خالی بگذارید. احراز هویت و فایروال همچنان برای شبکهٔ مشترک توصیه می‌شوند.

نشانی HTTP یا گواهی خودامضا را برای راحتی فعال نکنید. HTTPS می‌تواند جلوی Ollama/LM Studio روی خود کامپیوتر با reverse proxy محلی و گواهی معتبر برقرار شود. اعتبارسنجی نام، زنجیرهٔ گواهی و DNS خصوصی روی گوشی برقرار می‌ماند. دسترسی از ایران، قرارداد و تعرفهٔ سرویس‌ها به شبکه و حساب شما وابسته‌اند؛ دانا خطای واقعی را نمایش می‌دهد، فیلترینگ را حدس نمی‌زند. برای راه‌اندازی Google و Mac [راهنمای موتور‌ها](03-engine-guide-fa.md) را ببینید.

Android می‌تواند صفحهٔ محافظت‌شده را سیاه کند؛ هیچ دور زدن یا خواندن Accessibility روی آن نداریم. |
| ابزارهای محلی | یادداشت، تایمر، آلارم، بازکردن ساعت و تنظیمات وای‌فای/بلوتوث/صدا، پیش‌نویس تقویم و پیامک، اشتراک متن. تایمر/آلارم و پیش‌نویس به برنامهٔ سیستم فرستاده می‌شوند و به داشتن برنامهٔ مناسب وابسته‌اند. دانا SMS ارسال نمی‌کند، تقویم را مستقیم نمی‌نویسد و متن خروجی مدل را به Intent یا دستور اجرا تبدیل نمی‌کند. |

کلید پروفایل با AES-256-GCM و Android Keystore و دامنهٔ مقصد در AAD نگهداری می‌شود. تغییر میزبان یا قالب اجازهٔ انتقال کلید قبلی را نمی‌دهد. مسیرهای WAN و LAN فقط TLS مورد اعتماد، بدون redirect و بدون بازپخش درخواست تولید دارند. متن محلی و بایگانی در Room خصوصی‌اند اما کل دیتابیس رمزنگاری جدا ندارد. پشتیبان‌گیری Android برای برنامه و انتقال خودکار داده غیرفعال است. پاک کردن تاریخچه یا حافظه، دادهٔ دریافت‌شده توسط ارائه‌دهنده را پس نمی‌گیرد.

### ساخت و امضای انتشار شخصی

- از پوشهٔ `dana-android` و **JDK 21**، SDK 36 و Build Tools 36.0.0 استفاده کنید. Wrapper و کاتالوگ نسخه در مخزن‌اند. Gradle از مخازن رسمی و JitPack (فقط گروه/ماژول Tesseract4Android) استفاده می‌کند.

```bash
./gradlew --no-daemon :core:domain:test :core:data:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:assembleRelease
./gradlew --no-daemon :core:data:connectedDebugAndroidTest :app:connectedDebugAndroidTest
```

- خروجی پیش‌نمایش `app/build/outputs/apk/debug/app-debug.apk` با package `ai.dana.preview` است. ساخت release با R8، package جداگانهٔ `ai.dana` دارد. برای انتشار خصوصی از keystore پایدار خودتان و Android Studio **Generate Signed Bundle / APK** یا `apksigner` استفاده کنید؛ رمز و فایل کلید را در Git یا چت نگذارید. قبل از حذف پیش‌نمایش قبلی (اگر امضا متفاوت بود) یادداشت‌های موردنیاز را کپی کنید.

- [اجرای 44236151860](https://github.com/mrsad2615-creator/vodiwalker_panel/actions/runs/44236151860) بیلد debug و release بدون امضای انتشار، lint، سازگاری schema، امضای APK پیش‌نمایش و هم‌ترازی ۱۶ KiB فایل ZIP و کتابخانه‌های ۶۴ بیتی را بررسی کرد. ۳۱ آزمون JVM دامنه، ۱۲ آزمون JVM داده/شبکه، ۷ آزمون ذخیره‌سازی Android، ۲ آزمون تصویر و ۱۰ آزمون پروتکل پل مک روی Linux گذشتند.

- SHA-256 نسخهٔ منتشرشده `44e6cc48ae2e43d89823823e493bea4126419aa3f45e0cb762e90266b8924881` است. مرحلهٔ انتشار دوباره فایل را هش کرد؛ اندازه و digest ثبت‌شدهٔ release با همان artifact آزموده‌شده تطبیق دارند. آزمون‌های انتقال HTTPS/SSE با میزبان‌ها و پاسخ‌های کنترل‌شده اجرا شدند، نه کلید و سهمیهٔ سرویس‌های عمومی.

### آنچه هنوز نیاز به آزمون دستگاه یا توسعه دارد

تولید با حساب‌های واقعی، مک سازگار و دسترسی از شبکهٔ ایران به آزمایش جداگانه نیاز دارد. تست emulator وجود SDK/اجرای OCR و مسیرهای UI را نشان می‌دهد، نه کیفیت فارسی روی تمام تصاویر، نصب صدای فارسی روی گوشی‌های مختلف یا پوشش MediaProjection روی تمام سازنده‌ها. بیدارباش دائم، حالت دستیار سیستمی، Whisper یا صدای شبکه، برداشت خودکار متن با Accessibility، قفل بیومتریک اختصاصی برنامه، خلاصهٔ معنایی دورهای قدیمی و مدل مولد داخل گوشی در این نسخه ارائه نشده‌اند. این APK پیش‌نمایش با امضای دیباگ است، نه بستهٔ تأییدشدهٔ Play Store.
