# KAIROS (کایروس) — Luxury Productivity Android App

اپلیکیشن اندرویدی پریمیوم مدیریت وظایف، عادت‌ها، تقویم شمسی، تمرکز و تحلیل عملکرد با سبک طراحی **Luxury Minimal Cinematic** و رابط کاربری کاملاً فارسی (RTL) به همراه سیستم تایپوگرافی اختصاصی اعداد انگلیسی.

## هویت بصری و تایپوگرافی
- **پالت رنگی کنترل‌شده**:
  - Deep Black `#09090D`
  - Charcoal `#15141B`
  - Dark Purple `#241936`
  - Royal Purple `#8052D6`
  - Lavender `#B69AEF`
  - Soft White `#F4F1F8`
- **تایپوگرافی 100% آفلاین (Fontsource)**:
  - متن فارسی: `Vazirmatn`
  - اعداد شاخص و آمار بزرگ (Bold Condensed + Tabular): `Barlow Condensed`
  - اعداد هندسی دقیق، نمودارها و ساعت (Geometric Editorial + Tabular): `Space Grotesk` + `Manrope`

## صفحات و قابلیت‌های اصلی
1. **داشبورد (Dashboard)**: خوشامدگویی، تاریخ شمسی دقیق، حلقه پیشرفت روزانه، آمار بزرگ، کارهای مهم امروز، عادت‌های امروز، اهداف فعال و افزودن سریع کار.
2. **مدیریت وظایف (Tasks)**: نمای لیست هوشمند، برد کانبان (`To Do / In Progress / Completed`)، ماتریس چهارخانه آیزنهاور (`Q1–Q4`)، آرشیو، زیرکارها، تکرار خودکار بدون تکرار تکراری، برچسب‌ها، جست‌وجو، فیلتر و یادآوری.
3. **عادت‌ها و تقویم حرارتی 365 روزه (Habits & Heatmap)**: نقشه حرارتی سالانه با تفکیک دقیق روزهای **موفق**، **انجام‌نشده** و **ثبت‌نشده**، انتخاب سال‌های گذشته، صفحه اختصاصی هر عادت با رکورد متوالی، درصد پایبندی، نمودار روند و مقایسه ماهانه.
4. **تقویم شمسی (Calendar)**: نمایش ماهانه، هفتگی و روزانه شمسی بدون خطای منطقه زمانی، مشاهده وظایف و عادت‌های هر روز، و جابه‌جایی سریع تاریخ برنامه‌ها.
5. **محیط تمرکز (Focus Mode)**: محیط آرام و سینمایی شامل پومودورو و تایمر آزاد، اتصال به وظیفه، تداوم تایمر حین جابه‌جایی بین صفحات و ثبت خودکار جلسات.
6. **تحلیل و مرور ماهانه/سالانه (Analytics & Reviews)**: آمارهای واقعی محاسبه‌شده از پایگاه داده محلی، مرور ماهانه با مقایسه ماه قبل و تحلیل‌های هوشمند واقعی (Smart Insights)، و مرور سالانه با مقایسه 12 ماه.
7. **تنظیمات (Settings)**: پروفایل و اهداف روزانه، اعلان‌ها و تست اعلان، خروجی و بازیابی پشتیبان JSON، و پاک‌سازی/بارگذاری داده‌های نمونه.

## فناوری و معماری اندروید
- **Core**: React 19 + TypeScript (Strict) + Vite 6 + Tailwind CSS v4 + Framer Motion
- **ذخیره‌سازی پایدار آفلاین**: IndexedDB از طریق Dexie (`KairosLuxuryProductivityDB`)
- **بستر بومی اندروید**: Capacitor 8 (`kairos-app/android`) شامل پلاگین‌های:
  - `@capacitor/local-notifications`
  - `@capacitor/haptics`
  - `@capacitor/status-bar`
  - `@capacitor/splash-screen`
  - `@capacitor/app`
- **PWA آفلاین**: پشتیبانی کامل از نصب مستقیم روی اندروید (Service Worker + Web App Manifest)

## اجرای توسعه، تست و ساخت APK اندروید

```bash
cd kairos-app
npm install

# اجرای سرور توسعه
npm run dev

# بررسی تایپ، لینت و تست‌های خودکار
npm run typecheck
npm run lint
npm test

# ساخت نسخه تولید و همگام‌سازی پروژه بومی اندروید
npm run build
npx cap sync android

# ساخت فایل APK اندروید (در محیط دارای Android SDK / Java 21)
cd android && ./gradlew assembleDebug
```
