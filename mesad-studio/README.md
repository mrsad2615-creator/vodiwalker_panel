# MESAD Live Experience

Interactive luxury clock studio and time-management simulator. Start with `npm install && npm run dev` (binds 0.0.0.0). `npm test` runs precision calculations and timezone/calendar edge tests; `npm run build` validates production TypeScript and bundles WebGL experience.

The web studio uses actual Three.js/WebGL geometry and physically-based lighting/materials, not animated imagery. It mirrors the companion native Android app's three clock engines and safe-to-run user-facing flows; browser storage is local-first.
