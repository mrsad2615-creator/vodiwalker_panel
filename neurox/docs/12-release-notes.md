## تغییرهای این مرحله

هویت Quiet Precision، توکن‌ها و قلم محلی مشترک، آشنایی سه‌مرحله‌ای قابل ردکردن، تنظیمات پایدار، هدف روزانهٔ جدا برای هر پروفایل، صفحهٔ مستقل هر چهار استودیو، پیشنهاد تکلیف کم‌تمرین‌شده با دلیل روشن، نمودار روزانهٔ واقعی، شش دستاورد محاسبه‌شده بدون XP اضافی، حفظ وضعیت مسیرها، اصلاح بازکردن دوبارهٔ سنجش پایه و نشان راه‌انداز تطبیقی افزوده شدند. مهاجرت مخرب انجام نشد؛ Room همچنان نسخهٔ ۲ است. پنل Python حفظ شده است.

این مرحله هنوز همان ۱۴ تمرین واقعی را دارد. ۲۰ تمرین دیگر، Reading Studio و ورود متن، برنامه‌ریز پایدار، صدای مستقل/موسیقی، PIN/Keystore، سنجش پایهٔ کامل، مسیر یکپارچهٔ خروجی/بازیابی و پذیرش عملکرد/دسترس‌پذیری روی دستگاه واقعی باقی‌اند. هیچ‌یک با نمونهٔ طراحی جایگزین یا کامل اعلام نشده است.

دریافت و نصب محلی APK در این محیط انجام نشد. برای دورزدن ناسازگاری امضای debug نسخهٔ قبلی را حذف نکنید؛ دادهٔ محلی ممکن است از بین برود و بازیابی یکپارچه هنوز آماده نیست. گزارش زیر سابقهٔ نسخهٔ 0.4 است؛ برای نصب فعلی از لینک بالا استفاده کنید.

## قابلیت‌های پیاده‌سازی‌شده

### ۱۴ مسیر تمرینی واقعی از ۳۴ مسیر درخواستی

| سیستم | تمرین‌های موجود |
|---|---|
| VISION | Focus Lock، Visual Search، Pattern Match |
| REFLEX | Quick Tap، Go / No-Go، Shape Reaction، Color Reaction، Direction Match |
| READ | Reading Comprehension، Phrase Reading، RSVP Reader |
| TYPE | Key Precision، Word Sprint، Code Typing |

- زمان‌سنج یکنواخت، خطای زودهنگام، انتخاب اشتباه، هدف ازدست‌رفته، مکث و بازیابی دور ناتمام.
- الگوها و محرک‌های بذرپذیر، خودداری صحیحِ جدا از زمان واکنش، نمایش خواندن بدون ردکردن واژه‌های دیده‌نشده و محاسبهٔ سرعت از زمان واقعی.
- رنگ‌های محرک مستقل از پوسته و جهت فیزیکی پیکان مستقل از RTL؛ در سطح بالاتر، جای پیکان می‌تواند با جهت آن متفاوت باشد.
- تایپ Unicode و کد با حفظ فاصله و خط جدید؛ کد هرگز اجرا نمی‌شود. متن تایپ‌شده در تاریخچه ذخیره نمی‌شود.

### داده، تمرین‌ساز و رابط

- Kotlin/Compose، Room و DataStore؛ بدون وابستگی آنلاین ضروری یا مجوز اینترنت.
- پروفایل محلی، مهمان، تنظیمات، تاریخچه، علاقه‌مندی‌ها و پوسته‌های جداگانه.
- تمرین‌ساز با ۱۴ قالب محدود و غیرقابل‌اجرا به‌صورت کد دلخواه؛ نام، دورها، دشواری، پنجرهٔ پاسخ و معیار موفقیت.
- پیش‌نمایش، اجرای آزمایشی واقعی بدون XP، ذخیره، ویرایش، تکثیر و حذف؛ حفظ snapshot جلسات پس از حذف تعریف تمرین.
- رابط فارسی/انگلیسی، RTL/LTR، فونت محلی، پوستهٔ روشن/تیره و استودیو رنگ.
- قواعد تطبیقی محافظه‌کارانه با دلیل پیشنهاد و ثبت پذیرش/رد؛ محاسبهٔ XP بدون پاداش تکراری.
- رمزنگاری آزموده‌شدهٔ AES-256-GCM/PBKDF2 برای جزء پشتیبان؛ **نه مسیر کامل خروجی/بازیابی**.

### تقویت صحت ذخیره‌سازی

- checkpoint فقط‌افزایشی: پاسخ ثبت‌شده قابل بازنویسی نیست؛ افزودن پاسخ نمی‌تواند زمان فعال را کاهش دهد.
- snapshot قدیمی دادهٔ جدید را جایگزین نمی‌کند.
- لغو جلسه روی آخرین ردیف پایدار و در تراکنش انجام می‌شود؛ نوشتن در صف نمی‌تواند جلسهٔ لغوشده را دوباره فعال کند.
- مهاجرت افزایشی پایگاه دادهٔ ۱ به ۲؛ schema نسخهٔ ۲ از خروجی واقعی Room بازیابی و در سورس ثبت شده است.

## نتایج واقعی آزمون

| بررسی | نتیجه |
|---|---|
| هسته و رمزنگاری Kotlin | **۲۰۹ موفق، صفر ناموفق** |
| بررسی‌های ایستا و XML | **۳۶ موفق** |
| مهاجرت SQL و تطبیق با schema تولیدشده | **۵ موفق** |
| ابزار بازیابی شواهد CI | **۶ موفق** |
| نحو Kotlin/KTS | **۴۶ فایل، بدون خطای نحو** |
| کامپایل Android، Room/KSP، lint و بسته‌های آزمون | **موفق در CI** |
| شبیه‌ساز API 35، x86_64 | **۳۴ موفق، صفر ناموفق، صفر ردشده** |

آزمون‌های شبیه‌ساز شامل ۲۳ مورد داده/مهاجرت و ۱۱ مورد برنامه هستند. دو آزمون از ساعت واقعی و تایمر اصلی برنامه استفاده می‌کنند و پایان هدف بی‌پاسخ را در Room بررسی می‌کنند. آزمون‌های چیدمان از همگام‌سازی تایمر سریع جدا شده‌اند؛ غیرفعال‌کردن انتشار خودکار فقط در fixture آزمون است و رفتار نسخهٔ عادی را عوض نمی‌کند.

سوابق شکست‌ها، از جمله خطای ناوبری، امضای غیرـvoid آزمون JUnit و اثر انتظار Compose بر تایمر سریع، در [گزارش آزمون](08-test-report.md) حفظ شده‌اند. هیچ آزمون رفتاری ناموفق برای سبزشدن نتیجه حذف نشده است. این مجموعه به معنی آزمون سرتاسری همهٔ مسیرها روی همهٔ دستگاه‌ها نیست.

## کارهای باقی‌مانده؛ دامنه کاهش نیافته است

۲۰ تمرین دیگر، Reading Studio و ورود امن متن، برنامه‌ریز پایدار، تکمیل QUEST و SENSE، قفل PIN و Keystore، آواتار، سنجش پایهٔ هدایت‌شده، خروجی/بازیابی تراکنشی و امن، پشتیبان زمان‌بندی‌شده، کنترل‌های پیشرفتهٔ تمرین‌ساز، تحلیل و نمودارهای کامل، انیمیشن و سه حالت عملکرد هنوز باقی‌اند. فهرست تمرین‌های لازم در [ماتریس نیازمندی‌ها](02-product-requirements.md) ثبت شده است.

همچنین پذیرش روی دستگاه واقعی، TalkBack/Switch Access، کنتراست و فونت بزرگ، حالت پرواز، مصرف حافظه و باتری، نرخ فریم، ماتریس وقفه و خطا و امضای انتشار کامل نشده‌اند. موفقیت ساخت و ۳۴ آزمون فعلی به معنی تکمیل این موارد نیست.

## احتیاط برای دادهٔ کاربر

- تغییر پروفایل فعلاً جداسازی منطقی است، نه قفل امنیتی در برابر دارندهٔ دستگاه.
- پایگاه داده جز حفاظت فضای خصوصی Android، رمزنگاری‌شده نیست.
- مسیر یکپارچهٔ خروجی/بازیابی هنوز وجود ندارد؛ دادهٔ ارزشمند را در این نسخه نگهداری نکنید.
- کلید debug ممکن است میان اجراهای CI متفاوت باشد. برای دورزدن خطای امضا، نسخهٔ قبلی را حذف نکنید؛ حذف نصب دادهٔ محلی را نیز حذف می‌کند. از شبیه‌ساز یا دستگاه/پروفایل آزمایشی استفاده کنید.
- توقف ناگهانی فرایند می‌تواند آخرین نوشتن ناپایدار در صف را از بین ببرد؛ بازیابی از آخرین checkpoint پایدار انجام می‌شود.
- زمان واکنش از انتشار نرم‌افزاری محرک محاسبه می‌شود، نه از اندازه‌گیری فیزیکی اولین پیکسل. نتایج با و بدون ابزار کمکی مستقیماً قابل مقایسه نیستند.
- مجموعهٔ متن کوچک است و برای ارزیابی علمی کافی نیست. برنامه ادعای تشخیص یا درمان پزشکی ندارد.
- تاریخچه برای حجم بسیار زیاد داده هنوز به صفحه‌بندی و پردازش پس‌زمینهٔ بیشتر نیاز دارد.
