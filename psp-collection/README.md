# game — دو فایل ۱۰ گیگی، با یک کلیک

همین. یک فایل، یک دستور، دو تا ZIP.

```bash
python3 make.py
```

خروجی:

```
out/PSP_1_NOSTALGIA.zip     ← بازی‌های نوستالژی
out/PSP_2_GRAPHICS.zip      ← بازی‌های گرافیک بالا
```

هر کدام زیر ۱۰ گیگ. داخلشان پوشه‌ی `PSP/` با فایل‌های بازی. ZIP بدون فشرده‌سازی
(`ZIP_STORED`) ساخته می‌شود، پس **مستقیم با PPSSPP باز می‌شود** — استخراج جدا لازم نیست.
اگر خواستی اکسترکت کنی هم با هر ابزاری (WinRAR / 7-Zip / ZArchiver) باز می‌شود.

---

## تنها کاری که باید بکنی: لینک‌ها را بده

`links.txt` را باز کن و لینک‌های **مستقیم** فایل بازی را خط‌به‌خط بگذار:

```
https://example.com/God.of.War.Ghost.of.Sparta.USA.PSP.iso
https://example.com/Tekken.6.USA.PSP.iso
https://example.com/Daxter.USA.PSP.cso
```

بعد `python3 make.py`. همین.

اسکریپت:

1. لینک‌ها را دانلود می‌کند — با **ادامه‌ی دانلود**: اگر اینترنت قطع شد، دفعه‌ی بعد از
   همان‌جا که مانده ادامه می‌دهد (فایل‌های نیمه‌کاره در `.cache_dl/` می‌مانند).
2. آرشیوهای `.zip` / `.7z` / `.rar` را خودش باز می‌کند و `.iso` / `.cso` / `.chd` داخلشان را برمی‌دارد.
3. از **اسم فایل** تشخیص می‌دهد هر بازی به کدام پوشه می‌رود (`data/selection.json`).
4. حجم واقعی را می‌سنجد و تا ۹.۷ گیگ پر می‌کند؛ اگر بازی‌ای جا نشد، اسمش را چاپ می‌کند.
5. دو ZIP می‌سازد. همین دو تا. نه بیشتر.

---

## اگر لینک نداری، فایل‌ها را خودت بریز

پوشه‌ی `inbox/` را بساز و فایل‌ها را داخلش کپی کن — با هر اسمی، مهم نیست:

```bash
mkdir -p inbox
cp ~/Downloads/*.iso ~/Downloads/*.cso inbox/
python3 make.py
```

اسم‌ها لازم نیست تمیز باشند: `God of War - Ghost of Sparta (USA) (v2.00).iso`
خودش تشخیص داده می‌شود.

## سوییچ‌ها

| دستور | کار |
|---|---|
| `python3 make.py --plan` | فقط بگو چه چیزی داخل هر ZIP می‌رود، چیزی نساز |
| `python3 make.py --fresh` | ZIP های قبلی را پاک کن و از نو بساز |
| `python3 make.py --cap 9.5` | سقف حجم را عوض کن (پیش‌فرض ۹.۷ گیگ) |
| `python3 make.py --no-down` | دانلود نکن، فقط از `inbox/` بخوان |

## برای `.7z` و `.rar`

اگر لینک‌هایت آرشیو هستند:

```bash
pip install py7zr        # برای .7z
sudo apt install unrar   # برای .rar
```

بدون این‌ها هم اسکریپت کار می‌کند، فقط آرشیوهای `.7z`/`.rar` را باز نمی‌کند و
پیام می‌دهد. `.zip` و `.iso` و `.cso` بدون هیچ پیش‌نیازی کار می‌کنند.

## اگر ZIP از ۱۰ گیگ رد شد

این اتفاق نمی‌افتد چون سقف داخلی ۹.۷ گیگ است و اسکریپت بازی اضافه را حذف می‌کند.
اگر باز هم دیدی بزرگ‌تر شد (مثلاً فایل غیرمنتظره‌ای داخل پوشه بود)، با `--cap 9.4` اجرا کن.

برای صرفه‌جویی در حجم: بازی‌ها را به `.cso` تبدیل کن. PPSSPP هر دو را می‌خواند و
CSO حدود ۳۰٪ کم‌تر است — با همان `--cap` بازی بیشتری جا می‌شود.
