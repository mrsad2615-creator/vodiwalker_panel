# علوم هشتم | آمادگی جامع امتحان (فصل‌های ۱ تا ۴)

کتاب آمادگی امتحان علوم تجربی پایه هشتم برای سال تحصیلی ۱۴۰۵–۱۴۰۶، محدود به چهار فصل نخست.
همه فایل‌ها در پوشه `output/` آماده دانلود هستند.

## فایل‌های نهایی

| فایل | توضیح |
|---|---|
| `output/Science8_Complete_Exam_Guide_1405-1406.pdf` | کتاب کامل، ۱۱۶ صفحه، A4، راست‌به‌چپ، فونت وزیرمتن جاسازی‌شده، فهرست کلیک‌پذیر و ۳۰ نشانک |
| `output/Science8_Exam_Papers.pdf` | سه آزمون ۲۰ نمره‌ای بدون پاسخ + برگه پاسخ خالی (۱۰ صفحه) |
| `output/Science8_Answer_Key.pdf` | پاسخ‌نامه تشریحی سه آزمون (۶ صفحه) |
| `output/Science8_Research_Source_Report.pdf` | گزارش پژوهش و منابع، شامل محدودیت‌های تأیید نشده (۴ صفحه) |
| `output/Science8_QA_Report.pdf` | گزارش کنترل کیفیت با فهرست خطاهای پیدا‌شده و اصلاح‌شده (۳ صفحه) |

## ساختار محتوا

- جلد، صفحه مشخصات، راهنمای استفاده، فهرست مطالب کلیک‌پذیر، نقشه راه + برنامه ۷ روزه
- برای هر فصل: آموزش کامل (۸ مفهوم با «چیست/چرا/چگونه/مثال/ارتباط با امتحان/اشتباه رایج»)، نکات کلیدی، تحلیل فعالیت‌ها و آزمایش‌ها، تحلیل شکل‌ها، خلاصه تصویری، بانک ۳۹ سؤالی چهارسطحی، پاسخ‌نامه تشریحی
- مرور شب امتحان، واژه‌نامه (۲۲ اصطلاح)، جدول‌های مقایسه (۸)، اشتباه‌های رایج (۱۲)، تکنیک‌های حافظه (۸)، برگه‌های حفظی، چک‌لیست (۱۸ بند)، منابع، صفحه پایانی
- سه آزمون شبیه‌سازی‌شده ۲۰ نمره‌ای (هر یک ۱۶ سؤال، ۶۰ دقیقه) با پاسخ‌نامه و برگه پاسخ

## بازتولید

```bash
pip install reportlab matplotlib pillow arabic-reshaper python-bidi
python3 build_diagrams.py   # ۱۸ نمودار → assets/
python3 build_pdf.py        # سه PDF اصلی → output/
python3 build_reports.py    # گزارش پژوهش و گزارش QA → output/
```

## داده‌های محتوا

- `data_ch1.py` … `data_ch4.py`: مفاهیم، نکات، فعالیت‌ها، شکل‌ها و ۳۹ سؤال هر فصل
- `data_exams.py`: سه آزمون، واژه‌نامه، جدول‌های مقایسه، اشتباه‌های رایج، حافظه، چک‌لیست
- `build_diagrams.py`: نمودارهای علمی (matplotlib)
- `build_pdf.py`: سازنده PDF راست‌به‌چپ (ReportLab)
- `build_reports.py`: گزارش‌های پژوهش و QA
- `qa/`: رندرهای بازرسی چشمی صفحات

## محدودیت‌ها

- فایل رسمی کتاب درسی از `chap.sch.ir` هنگام تهیه با خطای HTTP 500 در دسترس نبود؛ ساختار و محتوا با منابع آموزشی هماهنگ با کتاب درسی تطبیق داده شد و این موضوع در کتاب و گزارش پژوهش صریحاً اعلام شده است.
- سؤال‌ها تمرینی و پیش‌بینی‌شده‌اند؛ هیچ سؤالی به امتحان واقعی با سال مشخص نسبت داده نشده است.
- متن فارسی PDF به شکل حروف نمایشی ذخیره شده است، بنابراین جست‌وجوی متنی ممکن است ناقص باشد؛ نمایش، چاپ، فهرست و نشانک‌ها سالم‌اند.
