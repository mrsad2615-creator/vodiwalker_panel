# TYPFLOW

اپلیکیشن اندرویدی تمرین **تایپ سریع** و **تندخوانی** با رابط کاربری سینمایی، چهار تم قابل انتخاب و ذخیره‌سازی کامل آفلاین.

- **پلتفرم:** Android 8+ (minSdk 26) · Kotlin + Jetpack Compose (Material 3)
- **حجم تقریبی APK:** ۸.۹ مگابایت · **بدون** تبلیغ، بدون حساب کاربری، بدون اینترنت
- **دانلود:** از صفحه [Releases](../../releases/tag/typflow-latest) فایل `TYPFLOW-1.0.0.apk` را بگیرید.
- **پیش‌نمایش وب:** پوشه [`typflow-web`](../typflow-web) — دموی تعاملی + صفحه دانلود.

## قابلیت‌ها

### تایپ
- تمرین فارسی و انگلیسی با متن‌های آمادهٔ آفلاین
- آزمون ۶۰ ثانیه‌ای با تایمر و نوار پیشرفت
- محاسبهٔ زندهٔ WPM، دقت درصدی و شمارش خطا
- رنگ‌آمیزی کاراکتر‌به‌کاراکتر (انگلیسی) و کلمه‌به‌کلمه (فارسی، برای حفظ اتصال حروف)
- ثبت رکورد شخصی و افزودن جلسه به تاریخچه

### تندخوانی
- نمایش کلمه‌به‌کلمه به روش **RSVP** با نشانگر نقطهٔ بهینهٔ خواندن (ORP)
- کنترل سرعت ۱۰۰ تا ۱۰۰۰ کلمه در دقیقه
- نمایش متن کامل و آزمون درک مطلب چندگزینه‌ای
- ثبت بهترین سرعت و درصد درک مطلب

### داشبورد، آمار و پروفایل
- سرعت تایپ، سرعت مطالعه، بهترین دقت و تعداد جلسات
- حلقهٔ هدف روزانه + مجموع زمان تمرین
- نمودار روند سرعت، نمودار میله‌ای ۷ روز اخیر و تاریخچهٔ جلسات
- ۸ دستاورد، سطح پیشرفت و رکوردها

### تنظیمات
- چهار تم مستقل با پیش‌نمایش زنده و اعمال **بدون راه‌اندازی مجدد**، ذخیره‌شده در دستگاه
  - **CYBER FUSION** — مشکی، فیروزه‌ای، هولوگرافیک
  - **OBSIDIAN** — مشکی، نقره‌ای، لوکس
  - **NEBULA** — بنفش، آبی نئون، آینده‌نگر
  - **MONOLITH** — مونوکروم مینیمال با تایپوگرافی حرفه‌ای
- تغییر زبان فارسی/انگلیسی با چیدمان RTL/LTR کامل
- هدف روزانه، لرزش و صدا، بازنشانی داده‌ها

## ساختار پروژه

```
typflow/
  app/src/main/java/com/typflow/app/
    MainActivity.kt          # نقطهٔ ورود (پشتیبانی از deep-link صفحه برای تست)
    theme/Theme.kt           # سیستم چهار-تمی + پالت‌ها
    data/Store.kt            # ذخیره‌سازی محلی با SharedPreferences
    data/Texts.kt            # متن‌ها و آزمون‌های درک مطلب آفلاین
    ui/                      # Splash، Home، Typing، Reading، Analytics، Profile، Settings
scripts/
  smoke.sh                   # تست دودی روی شبیه‌ساز اندروید
  ui_click.py                # کمکی برای لمس هدفمند در تست
typflow-web/                 # صفحه دانلود + دموی تعاملی وب
.github/workflows/build-apk.yml   # ساخت APK + تست شبیه‌ساز + انتشار در Release
```

## ساخت و تست

```bash
# بیلد محلی
cd typflow && gradle :app:assembleDebug

# بیلد + تست خودکار (GitHub Actions)
git push        # روی برنچ‌های arena/** یا main
```

هر push به برنچ، این موارد را انجام می‌دهد: بیلد APK دیباگ → انتشار در Release با تگ `typflow-latest` → نصب و اجرای اپ روی شبیه‌ساز اندروید ۳۰ → لمس واقعی همهٔ صفحات، تغییر تم و زبان، یک سشن تایپ → ذخیرهٔ اسکرین‌شات‌ها در `telemetry/` و بررسی نبود کرش.

## طراحی

- پس‌زمینهٔ سینمایی با هاله‌های نورانی و وینیت، پنل‌های شیشه‌ای (Glassmorphism)
- لوگوموشن «mrsad» با گرادیان هولوگرافیک و هالهٔ چرخان در صفحهٔ ورود
- اعداد انگلیسی درشت برای متریک‌ها، انیمیشن نرم اعداد و نوارهای پیشرفت
- تایپوگرافی تمیز، فاصله‌گذاری منظم و محیط متمرکز در هنگام تمرین
